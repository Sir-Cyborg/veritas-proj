APPLICATION SECURITY TESTING PROCESS
Corporate Banking Group


1. Introduction

Application security testing is a key control to identify vulnerabilities
before applications are deployed into production.


2. Objectives

The objectives of this process are to:
- Detect security weaknesses early
- Reduce remediation costs
- Improve overall software quality


3. Types of Security Testing

3.1 Static Application Security Testing (SAST)  
Analysis of source code to identify potential vulnerabilities.

3.2 Dynamic Application Security Testing (DAST)  
Testing of running applications to detect runtime vulnerabilities.

3.3 Penetration Testing  
Simulated attacks performed by specialized teams.


4. Testing Frequency

Security testing must be performed:
- Before production deployment
- After major changes
- Periodically for critical applications


5. Vulnerability Management

Identified vulnerabilities are classified by severity and tracked until closure.


6. Reporting

Testing results are documented and shared with development and risk management teams.
